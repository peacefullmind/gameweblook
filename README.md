# 游戏网站监控系统

## 项目概述

这是一个专门用于监控多个游戏网站的自动化系统，通过定期检查网站的 Sitemap 和 RSS 源来追踪新游戏发布和内容更新。该系统可以帮助游戏爱好者、开发者或内容创作者及时了解游戏行业的最新动态。

## 功能特点

- **多站点监控**：同时监控多个游戏网站，包括 CrazyGames、NealFun、GameDistribution、Miniplay、GameFlare、itch.io、Poki 和 1games 等。
- **多种数据源支持**：支持通过 Sitemap XML 和 RSS 源两种方式获取网站更新信息。
- **自动化检测**：定期自动检查配置的网站，识别新增的游戏内容。
- **数据存储**：将获取到的 Sitemap 和 RSS 数据保存到本地，方便后续分析和处理。
- **更新日志**：记录新增页面信息，便于追踪网站内容变化。

## 配置说明

系统通过 `config.yaml` 文件进行配置，主要包含以下部分：

### 网站配置

```yaml
websites:
  - name: 网站名称
    url: 网站主页URL
    sitemap: 网站的Sitemap URL
```

或者对于提供 RSS 源的网站：

```yaml
websites:
  - name: 网站名称
    url: 网站主页URL
    rss: 网站的RSS URL
```

### 存储配置

```yaml
storage:
  sitemap_dir: sitemaps  # Sitemap文件保存目录
  log_dir: logs          # 新增页面日志保存目录
  rss_dir: rss           # RSS文件保存目录
```

## 当前监控的网站

1. **CrazyGames** - 提供各种类型的免费在线游戏
2. **NealFun** - 提供创意互动体验和小游戏
3. **GameDistribution** - 大型HTML5游戏分发平台
4. **Miniplay** - 提供多种类型的免费在线游戏
5. **GameFlare** - 提供各种Flash和HTML5游戏
6. **itch.io** - 独立游戏开发者平台
7. **Poki** - 提供精选的在线游戏
8. **1games** - 提供多种类型的免费在线游戏

## 使用方法

1. 确保已安装所需的依赖包
2. 根据需要修改 `config.yaml` 配置文件
3. 运行主脚本开始监控过程
4. 查看 logs 目录下的日志文件获取新增游戏信息

## 数据存储结构

- **sitemaps/** - 存储从各网站获取的 Sitemap XML 文件
- **rss/** - 存储从支持 RSS 的网站获取的 RSS 源数据
- **logs/** - 存储监控过程中发现的新增页面信息

## 扩展与定制

系统设计为易于扩展，您可以通过以下方式进行定制：

1. 在 `config.yaml` 中添加新的游戏网站
2. 调整检查频率以满足特定需求
3. 开发额外的数据处理模块以分析收集到的信息

## 注意事项

- 请确保遵守各网站的爬虫政策和使用条款
- 建议设置合理的检查间隔，避免对目标网站造成过大负担
- 定期清理旧数据以节省存储空间

## 技术实现

该系统主要通过解析 XML 格式的 Sitemap 和 RSS 源来获取网站更新信息。系统会比较当前获取的数据与历史数据的差异，从而识别新增内容。
